# Changelog

All notable changes to this project will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Changed

- Renamed the app and executable to lowercase `slskdbar`.
- Added a Finder application icon and release DMG packaging.

## [2.0.0] - 2026-07-31

### Added

- Native macOS menu bar interface with clear section headings.
- Event-driven slskd and Soulseek connection status.
- Connect and disconnect controls.
- On-demand transfer summaries and completed-transfer cleanup.
- Dashboard, download, config, log, and data shortcuts.
- Nicotine+ and SoulseekQt discovery, launch actions, and download links.
- Optional active transfer counts beside the status icon.
- Settings for launch at login, notifications, locations, apps, and status
  icons.
- White, color, green, and red connection-state icons.
